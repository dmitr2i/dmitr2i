### What I do

**Content and audience growth**
- Build daily short-form content systems: videos, carousels and text posts with a fixed story arc (hook, problem, turn, proof, payoff).
- Plan posting schedules for each network (Instagram, Threads, X, TikTok, LinkedIn) and automate them through Postiz.
- Run research bots for trends, news, fact-checking and comment replies. They draft; a person publishes.

**Ad creative**
- Tear down viral ads and reels (transcripts plus frame-by-frame reads) and turn what works into reusable formats.
- Write and test hooks; score angles and formats as Winner, Loser or Testing from real views.
- Brief and produce statics, carousels and short videos, including UGC-style scripts.

**Go-to-market and launches**
- Score segments and channels before spending anything, then run cheap tests and decide after a set number of conversations.
- Write launch kits for Product Hunt, Show HN, Indie Hackers, Reddit and LinkedIn, plus startup-directory lists.
- Run outbound: personalised, compliant cold email and sequences.
- Build programmatic SEO: competitor comparison pages, guides and OG cards.
- Set up attribution with first-touch source tags on every signup.

**Marketing automation**
- Build agent workflows and MCP tools so Claude can research, write, render and schedule marketing.

### How I work
- **Test cheaply, then decide on data.** Score ideas first, run small tests, and keep what converts.
- **Never fake proof.** No invented reviews, numbers, testimonials or staged UGC, in my own content or in what my tools generate.
- **Automate the repetitive parts.** Research, drafting, rendering and scheduling run through agents; judgment and publishing stay with a person.
- **Study what works, copy the formula, not the post.** I tear down top ads and reels, then rebuild the structure with my own material.
